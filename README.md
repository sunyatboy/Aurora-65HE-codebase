# Aurora-65HE-codebase
Aurora 65 HE Keyboard created for Fallen in Hack Club. What makes this keyboard special is that the actuation points will change based on your typing habits. For example, if I was typing, "typin", the actuation point of F would be much lower while G would be higher for that next letter, and it changes every key you type. 
## Toolchain
gcc.exe (Rev4, Built by MSYS2 project) 16.2.0
GNU gdb (GDB) 18.1
GNU Make 4.4.1
